Event Booking and Hosting Platform [SwagTix]

SwagTix is an advanced event ticket booking platform inspired by BookMyShow, developed using .NET Core MVC. It supports multiple user roles including normal users, event hosts, and a super admin. The system allows users to book tickets with real-time seat selection, while hosts can manage venues, assign ticket pricing per row, and upload event media. SwagTix integrates dynamic pricing, JSON-based seat management, and a scalable database structure for real-world applications.

Task Management App [MyToDoo]

MyToDoo is a personal productivity web app that helps users manage their tasks effortlessly. Built using .NET Core MVC, it enables users to add, update, and delete tasks with real-time status updates using AJAX. With features like task prioritization, due dates, and reminder times, the project aims to demonstrate how small utilities can be built with clean code structure, proper validations, and a focus on user experience.
